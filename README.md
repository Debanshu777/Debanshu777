# Debanshu Datta — Android & Kotlin Multiplatform Developer

I'm an Android Engineer 2 at [Groww](https://github.com/Groww), building with **Kotlin Multiplatform, Compose Multiplatform, and Jetpack Compose**. I share practical tutorials and open-source projects for Android and cross-platform development.

## Featured projects

- [XCalendar — Compose Multiplatform calendar app](https://github.com/Debanshu777/XCalendar): a calendar application for Android, iOS, and desktop.
- [ShaderX — GPU shader effects for Compose Multiplatform](https://github.com/Debanshu777/ShaderX): a Kotlin API for shader effects, with platform support and limitations documented in the repository.
- [Popp — CameraX and Jetpack Compose camera app](https://github.com/Debanshu777/Popp): photo and video capture, concurrent cameras, and picture-in-picture recording.
- [Compose Snapchat Clone](https://github.com/Debanshu777/Compose-Snapchat-Clone): an Android sample using Jetpack Compose and Material 3.
